# PRD: 대시보드 증감 제거 및 포트폴리오 상세 수정

## 1. 배경

- 대시보드의 지난달 대비 순자산 증감 표시가 현재 데이터 구조에서 신뢰 가능한 값으로 안정적 계산 어려움
- 자산별 현재 금액을 배분 흐름과 분리해 포트폴리오 상세에서 직접 수정할 필요
- 월별 흐름 원천 데이터인 `allocations`는 유지하면서 현재 자산 금액 수정 책임 분리 필요

## 2. 목표

- 대시보드에서 지난달 대비 순자산 증감 표시 제거
- 포트폴리오 상세에서 자산별 `currentBalance` 직접 수정
- 배분 내역 기반 월별 흐름 구조 유지
- 총합 보정용 조정 자산 없이 실제 자산 금액 직접 업데이트

## 3. 범위

### 포함

- 대시보드의 지난달 대비 증감 계산 및 표시 제거
- 포트폴리오 상세 편집 모드 추가
- 자산별 금액 입력 UI 추가
- 자산 `currentBalance` 업데이트 저장 로직 추가
- 저장 성공 후 `assets` 쿼리 무효화

### 제외

- `allocations` 데이터 구조 변경
- 자산 추가/삭제 기능 구현
- 포트폴리오 상세 화면의 대규모 디자인 개편
- 일부 저장 실패 시 롤백 정책 구현

## 4. 요구사항

| ID | 요구사항 | 완료 기준 |
| --- | --- | --- |
| REQ-1 | 대시보드 증감 표시 제거 | `lastMonthDiff` 계산과 원형 차트 중앙 증감 배지 제거 |
| REQ-2 | 요약 카드 표시 단순화 | 투자 자산과 현금 보유만 표시 |
| REQ-3 | 포트폴리오 상세 편집 모드 제공 | 우측 상단 `편집` 버튼으로 수정 모드 진입 |
| REQ-4 | 편집 중 취소/저장 제공 | 편집 상태에서 `취소`와 `저장` 버튼 표시 |
| REQ-5 | 자산별 금액 직접 수정 | 각 자산 카드의 금액 위치가 입력창으로 전환 |
| REQ-6 | 빈 값 저장 방지 | 빈 값이 있으면 저장하지 않고 사용자에게 상태 표시 |
| REQ-7 | 자산 금액 저장 후 캐시 갱신 | 저장 성공 시 `assets` 쿼리 무효화 |

## 5. 참고 맥락

- 관련 파일:
  - `components/dashboard/PortfolioList.tsx`
  - `app/(tabs)/index.tsx`
  - `hooks/useUpdateAssets.ts`
  - `services/asset/asset.service.ts`
  - `repositories/asset.repository.ts`
- 변경 원칙:
  - `allocations`는 월별 배분 원천 데이터로 유지
  - 대시보드 카드는 요약 정보만 표시
  - 자산 수정은 포트폴리오 상세에서만 수행
  - 저장 시 해당 자산의 `currentBalance` 직접 업데이트
- 리스크:
  - 자산 수 증가 시 편집 모드 입력 부담 증가 가능
  - 다수 자산 저장 시 일부만 실패하는 경우 후속 처리 규칙 필요 가능
  - 향후 자산 추가/삭제 기능과 연결 UX 별도 정리 필요 가능

## 6. 작업 계획

진행 규칙: 1번부터 순서대로 하나씩 진행하며, 각 단계마다 `작업 완료 → 자체 검증 → 필요 시 수정 또는 사용자 확인 → 사용자 검수 → 다음 단계 진행` 순서 준수

1. 대시보드에서 `lastMonthDiff` 계산 제거
2. 원형 차트 중앙의 증감 배지 제거
3. 요약 카드가 투자 자산과 현금 보유만 표시하도록 정리
4. 자산 수정용 service 또는 hook 추가
5. 자산 단위 `currentBalance` 업데이트 저장 로직 구현
6. 저장 성공 후 `assets` 쿼리 무효화
7. 포트폴리오 상세 섹션 우측 상단에 `편집` 버튼 추가
8. 편집 상태에서 `취소`와 `저장` 버튼 표시
9. 각 자산 카드의 금액 영역을 입력 상태로 전환
10. 취소 시 입력 상태 초기화 후 표시 모드로 복귀

## 7. 검증

- 대시보드에서 지난달 대비 증감 텍스트와 배지 미표시 확인
- 요약 카드가 투자 자산과 현금 보유만 표시하는지 확인
- 포트폴리오 상세에서 편집, 취소, 저장 흐름 동작 확인
- 저장 시 자산별 `currentBalance` 직접 업데이트 확인
- 저장 성공 후 대시보드와 포트폴리오 상세 데이터 갱신 확인
