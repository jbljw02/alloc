# 대시보드 증감 제거 및 포트폴리오 상세 수정 계획

## 목표

- 대시보드에서 지난달 대비 순자산 증감 표시를 제거
- 포트폴리오 상세에서 자산별 금액을 직접 수정
- 기존 `allocations` 기반 월별 흐름 구조는 유지

## 변경 원칙

- `allocations`는 그대로 월별 배분 원천 데이터로 유지
- 대시보드 카드는 요약 정보만 표시
- 자산 수정은 포트폴리오 상세에서만 수행
- 총합 보정용 조정 자산을 만들지 않음
- 저장 시 해당 자산의 `currentBalance`를 직접 업데이트

## 자산 수정 규칙

- 포트폴리오 상세 우측 상단의 `편집` 버튼으로 수정 모드 진입
- 수정 모드에서는 각 자산 카드의 금액 영역을 입력 상태로 전환
- `취소`를 누르면 입력 상태를 초기화하고 표시 모드로 복귀
- `저장`을 누르면 수정된 자산 금액을 반영
- 빈 값이 있으면 저장하지 않음

## 구현 범위

### 1. 대시보드 표시 단순화

- `lastMonthDiff` 계산 제거
- 원형 차트 중앙의 증감 배지 제거
- 요약 카드에서는 투자 자산과 현금 보유만 표시

### 2. 포트폴리오 상세 수정 저장 로직 추가

- 자산 수정용 서비스 또는 훅 추가
- 자산 단위로 `currentBalance` 업데이트
- 저장 후 `assets` 쿼리 무효화

### 3. 포트폴리오 상세 수정 UI 추가

- 포트폴리오 상세 섹션 우측 상단에 `편집` 버튼 추가
- 편집 상태에서 상단에 `취소` / `저장` 버튼 표시
- 각 자산 카드의 금액 위치는 유지한 채 입력창으로 전환

## 의도한 동작

- 사용자는 포트폴리오 상세에서 자산 단위로 금액을 직접 수정
- 대시보드는 현재 총 순자산과 자산 구성을 요약해서 표시
- 지난달 대비 증감 정보는 더 이상 표시하지 않음

## 리스크

- 자산 수가 많아질수록 편집 모드 입력 부담이 커질 수 있음
- 다수 자산 저장 시 일부만 실패하는 경우 후속 처리 규칙이 필요할 수 있음
- 향후 자산 추가/삭제 기능과의 연결 UX는 별도 정리 필요
