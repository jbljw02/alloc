# 대시보드 총자산 수정 및 증감 제거 계획

## 목표

- 대시보드에서 지난달 대비 순자산 증감 표시를 제거
- 대시보드에서 총자산 수정 기능을 제공
- 기존 `allocations` 기반 월별 흐름 구조는 유지

## 변경 원칙

- `allocations`는 그대로 월별 배분 원천 데이터로 유지
- 총자산 수동 수정은 월별 증감 계산에 연결하지 않음
- 총자산 수정은 자산별 재분배가 아니라 현재 총합만 맞추는 기능으로 제한
- 총자산 수정 차이는 전용 현금 자산 하나에 반영

## 총자산 수정 규칙

- 대시보드에서 목표 총자산 값을 입력
- 현재 총자산과 목표 총자산의 차이를 계산
- 이름이 `총자산 조정`인 `CASH` 자산이 있으면 그 자산의 `currentBalance`를 업데이트
- 해당 자산이 없으면 `총자산 조정` 자산을 새로 만들고 차이값을 잔액으로 저장
- 차이값이 `0`이면 저장하지 않음

## 구현 범위

### 1. 대시보드 표시 단순화

- `lastMonthDiff` 계산 제거
- 원형 차트 중앙의 증감 배지 제거

### 2. 총자산 수정 저장 로직 추가

- 총자산 수정용 서비스 또는 훅 추가
- 자산 목록을 기준으로 현재 총자산 계산
- 총자산 차이를 `총자산 조정` 자산에 반영
- 저장 후 `assets` 쿼리 무효화

### 3. 대시보드 수정 UI 추가

- 대시보드에서 총자산 수정 모드 진입 버튼 추가
- 현재 총자산을 기본값으로 입력 필드에 표시
- 저장과 취소 버튼 제공

## 의도한 동작

- 사용자는 대시보드에서 총자산만 빠르게 보정
- 포트폴리오 상세는 기존 자산 + `총자산 조정` 자산 합으로 유지
- 지난달 대비 증감 정보는 더 이상 표시하지 않음

## 리스크

- `총자산 조정` 자산이 포트폴리오 상세에 노출됨
- 총자산 수정은 자산 구성 비율까지 의미 있게 보정하지 않음
- 향후 자산별 수정 UX가 생기면 규칙 재검토 필요
